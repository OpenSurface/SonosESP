# Demo album art

The covers in this folder are used by the interactive panel demo on the home
page (`docs/.vitepress/theme/PanelDemo.vue`), so that skipping a track changes
the artwork the way it does on a real panel.

They were fetched from the [Cover Art Archive](https://coverartarchive.org/),
the MusicBrainz cover-art project, by release-group:

| File | Album | MusicBrainz release-group |
|---|---|---|
| `souls-at-zero.jpg`  | Neurosis — *Souls at Zero* (1992)            | `a9304513-564c-3984-9c57-734f5a0edbd7` |
| `times-of-grace.jpg` | Neurosis — *Times of Grace* (1999)           | `d59a4f3e-b304-3b47-8784-7a7a4ea9922d` |
| `through-silver.jpg` | Neurosis — *Through Silver in Blood* (1996)  | `fb27225e-e66e-37ea-bc2c-9b7352f1e81f` |
| `oceanic.jpg`        | Isis — *Oceanic* (2002)                      | `2426e089-b3e2-3513-b43e-f1b73fb54e60` |
| `streetcleaner.jpg`  | Godflesh — *Streetcleaner* (1989)            | `2c784b05-145c-43f2-aca2-7ce3f4e6daf5` |
