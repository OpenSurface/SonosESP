Photos of other people's builds go here.

Add one by dropping the image in this folder and appending an entry to the
`community` array in `docs/.vitepress/theme/HomeBody.vue`:

    { src: '/community/your-file.jpg', who: 'name or @handle', note: 'kitchen wall' }

The homepage section stays hidden while that array is empty, so an unpopulated
folder does not leave a blank heading on the site.

Only add a photo the person actually sent in, and credit them with whatever name
they asked for. These are their builds, not ours.
