# First-time setup

1. **Power on.** If no Wi-Fi is configured, the setup screen appears on its own.
2. **Wi-Fi.** Tap *Scan*, choose your network, type the password on the
   on-screen keyboard.
3. **Find your speakers.** Go to *Settings → Speakers → Scan*.
4. **Play something.** Pick a room and you are controlling music.

Everything is stored in flash and survives reboots and firmware updates, so this
is a one-time job.

::: tip Wi-Fi is 2.4 GHz only
If your router broadcasts 2.4 GHz and 5 GHz under a single name, the board may
fail to join. Splitting them, or temporarily disabling 5 GHz, usually sorts it.
:::

## Getting around

The player is the home screen. From there:

- **Settings** — speakers, groups, sources, display, Wi-Fi, clock, updates
- **Sources** — everything you can play, see [Music sources](/guide/sources)
- **Queue** — what is lined up now

Leave it idle and it switches to a clock. Touch the screen to come back.
