Requirements

  • A supported board — the one selected above.
  • A data-capable USB-C cable (charge-only cables won't work).
  • Chrome, Edge, or Opera on desktop — needs the Web Serial API (Safari / Firefox / mobile are not supported).
  • A 2.4 GHz WiFi network and at least one Sonos speaker on the same LAN.
